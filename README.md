## 使用方法
1. 双击MH3GHDSaveEditor.exe启动程序。
2. 点击【打开存档】，选择存档并打开。打开后则会显示当前角色的名字、性别、金钱和资源点数。
3. 点击左侧栏【道具箱修改】，进行道具的修改。
4. 点击左侧栏【装备箱修改】，进行装备修改。
5. 修改完成后，点击左侧栏回到【角色信息】页面，点击【保存并关闭存档】进行保存。或者直接关闭窗口，会弹出提示是否要保存。
6. 保存完成后，会自动备份一份存档，放在程序根目录的**backup/yyyyMMddHHmmss**目录下，时间为保存修改时的时间。若不想使用自动备份功能，可在页面上方的【设置】选项中关闭。
7. 若没有想要修改的装备，可在程序根目录的**data**目录下，修改对应的json文件，自行添加 **{Id，Name}** 对。

## 注意事项
1. 当修改了装备箱中穿着在身上的装备时，脱下后即可看到修改后的内容。
2. 当将装备修改为（空）时，其上的装饰品也会消失，需要注意。
